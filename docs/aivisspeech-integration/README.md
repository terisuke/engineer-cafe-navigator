# AivisSpeech Engine 統合ガイド

このドキュメントセットは、Engineer Cafe NavigatorプロジェクトにAivisSpeech Engineを統合し、日本語音声合成をGoogle TTSから移行するための包括的なガイドです。

## 🆕 更新情報（2024年1月）

重要な変更点：
- **CORSポリシー**: `--cors_policy_mode all` を追加して、すべてのドメインからのアクセスを許可
- **デフォルトモデル**: UUID `a59cb814-0083-4369-8542-f51a29e72af7` のデフォルトボイスモデルを使用
- **スピーカーID**: デプロイ後に`/speakers`エンドポイントで実際のIDを確認が必要

## 📋 概要

AivisSpeech Engineは、VOICEVOX ENGINEをベースとした高品質な日本語音声合成システムです。本ガイドでは、GCP Cloud Run上にAivisSpeechをデプロイし、既存のGoogle TTS実装と共存させながら、日本語音声のみをAivisSpeechに切り替える方法を説明します。

### 主な特徴

- **VOICEVOX互換API**: 既存のVOICEVOXクライアントとの高い互換性
- **感情豊かな音声合成**: 複数の話者と感情表現に対応
- **Cloud Runでのスケーラブルなデプロイ**: 自動スケーリングとコスト最適化
- **フォールバック対応**: Google TTSへの自動フォールバック機能


### 3. デプロイ実行
詳細は[デプロイガイド](./DEPLOYMENT-GUIDE.md)を参照してください。

特に重要なポイント：
- AivisSpeech Engineは `--cors_policy_mode all` オプション付きで起動されます
- デフォルトボイスモデルが自動的に使用されます
- デプロイ後、`/speakers`エンドポイントで実際のスピーカーIDを確認してください

## ⚠️ 重要な注意事項

1. **API互換性**: AivisSpeechは一部のVOICEVOX APIをサポートしていません
   - `/speakers`, `/singer_info` などは利用不可
   - 話者情報は事前に設定ファイルで管理

2. **コールドスタート**: 初回起動時に遅延が発生する可能性があります
   - プロダクション環境では `min-instances: 1` の設定を推奨

3. **コスト管理**: Cloud Runの課金に注意
   - 開発環境: `min-instances: 0` でコスト最適化
   - 本番環境: パフォーマンスとコストのバランスを考慮

4. **CORSポリシー**: `--cors_policy_mode all` で起動
   - すべてのドメインからのアクセスを許可
   - セキュリティ要件に応じて本番環境では調整を検討

5. **デフォルトモデル**: UUID `a59cb814-0083-4369-8542-f51a29e72af7` を使用
   - カスタムモデルがない場合はデフォルトを利用
   - スピーカーIDは実際のデプロイ後に`/speakers`エンドポイントで確認
